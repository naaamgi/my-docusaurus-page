OWASP crAPI

OWASP crAPI 실습과 풀이 기록

📄️C1. 타 사용자의 차량 정보 조회

OWASP crAPI에서 차량 위치 API의 객체 수준 권한 검사를 확인한 기록

📄️C2. 타 사용자의 정비 보고서 조회

OWASP crAPI의 정비 보고서 API에서 객체별 권한 검사를 확인한 기록

📄️C3. 타 사용자의 비밀번호 재설정

OWASP crAPI에서 짧은 OTP와 구버전 비밀번호 재설정 API를 이용한 계정 탈취를 확인한 기록

📄️C4. 타 사용자의 민감 정보가 노출

OWASP crAPI의 커뮤니티 게시글 API가 다른 사용자의 이메일과 차량 ID를 반환하는 것을 확인한 기록

📄️C5. 동영상 API에서 내부 속성 찾기

OWASP crAPI의 프로필 동영상 API 응답에서 내부 처리 속성 conversion_params가 노출되는 흐름을 정리

📄️C6. Layer 7 DoS

OWASP crAPI의 Contact Mechanic 요청에서 반복 제어값을 조작해 서비스 가용성 저하를 유발한 기록

📄️C7. 다른 사용자의 동영상 삭제

OWASP crAPI의 관리자 동영상 삭제 API에서 기능 수준 권한 검증 누락을 확인한 기록

📄️C8. 주문 및 반품 조작 요청

OWASP crAPI 주문 API에서 대량 할당으로 주문 수량을 조작해 부당 반품 요청을 생성한 기록

📄️C9. 반품 조작으로 크레딧 획득

OWASP crAPI 주문 API에서 수량과 반품 상태를 조작해 크레딧을 부당하게 증가시킨 기록

📄️C10. 동영상 내부 속성 수정

OWASP crAPI 동영상 API에서 내부 변환 속성을 수정할 수 있는 대량 할당 취약점을 확인한 기록

📄️C11. Contact Mechanic API의 SSRF

OWASP crAPI Contact Mechanic 요청에서 외부 URL을 지정해 서버 측 요청을 유도한 기록

📄️C12. NoSQL Injection으로 쿠폰 코드 획득

OWASP crAPI 쿠폰 검증 API에서 NoSQL 연산자를 주입해 유효 쿠폰을 획득한 기록

📄️C13. SQL Injection

OWASP crAPI 쿠폰 적용 API의 SQL Injection으로 중복 확인 쿼리 결과가 응답에 반영되는 문제를 재현한 기록

📄️C14. 인증 없이 주문 상세 정보 접근

OWASP crAPI 주문 상세 조회 API가 Authorization 헤더 없이 주문 정보를 반환하는 문제를 재현한 기록

📄️C15. JWT 서명 검증 누락으로 타 계정 대시보드 조회

OWASP crAPI 대시보드 API가 변조된 JWT의 서명을 검증하지 않고 sub 클레임을 신뢰하는 문제를 재현한 기록
