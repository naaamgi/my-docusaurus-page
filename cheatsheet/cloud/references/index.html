참고자료 (References & Resources)

원본 출처​

CloudPentestCheatsheets​

이 문서는 다음 프로젝트를 기반으로 작성되었습니다:

저자: Beau Bullock (@dafthack) GitHub: CloudPentestCheatsheets

Beau Bullock과 클라우드 보안 커뮤니티의 모든 기여자분들께 감사드립니다.

📚 학습 사이트​

HackTricks Cloud​

URL: https://cloud.hacktricks.xyz/

설명:

  • AWS, Azure, GCP 취약점 및 공격 기법
  • 상세한 설명과 예제
  • 실전 시나리오

추천 대상:

  • 클라우드 침투테스트 초급~중급자
  • 체계적인 학습 원하는 분

PayloadsAllTheThings​

URL: https://github.com/swisskyrepo/PayloadsAllTheThings

설명:

  • 다양한 공격 페이로드 모음
  • AWS, Azure, GCP 섹션 포함
  • 복사해서 바로 사용 가능

OWASP Cloud Security​

URL: https://owasp.org/www-project-cloud-security/

설명:

  • 클라우드 보안 베스트 프랙티스
  • 일반적인 취약점 목록
  • 방어 전략

URL: http://flaws.cloud 플랫폼: AWS

설명:

  • S3, IAM, EC2 취약점
  • 무료, 가이드 제공

추천:

  • AWS 입문자
  • S3 공격 학습

Flaws2 Cloud​

URL: http://flaws2.cloud 플랫폼: AWS

설명:

  • Flaws의 후속편
  • 공격자/방어자 두 관점
  • 더 어려운 난이도

Thunder CTF (GCP)​

URL: http://thunder-ctf.cloud 플랫폼: GCP

설명:

  • GCP 전용 CTF
  • 실제 취약점 시나리오
  • 무료
