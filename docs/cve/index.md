# CVE 분석

공식 보안 권고와 제품 코드를 바탕으로 취약 조건과 원인을 분석한다. 재현 단계에서는 정상 요청과 우회 요청, 수정 버전을 같은 조건에서 비교해 증적을 남긴다. **실행하지 않은 실험은 결과로 쓰지 않는다.**

## 현재 공부하는 CVE

| 사례 | 먼저 잡을 질문 | 상태 |
| --- | --- | --- |
| [CVE-2025-29927 · Next.js Middleware 인증 우회](./cve-2025-29927.md) | 외부 요청 헤더가 Middleware 실행 판단에 영향을 주는 이유 | 취약점 분석 완료 · 직접 재현 전 |

분석글은 **영향 조건 → 원인 코드 → 재현 조건과 증적 → 진단 → 조치와 재검증** 순서로 작성한다. 필요한 용어는 해당 분석 위치에서 간단히 풀이한다.
