Tmux

\n

기본 단축키​\n

\n
\n
\n\n\n# 윈도우 표시\n
\n\n\nctrl b + w\n
\n\n\n\n\n
\n\n\n# 수평 분할\n
\n\n\nctrl b + "\n
\n\n\n\n\n
\n\n\n# 수직 분할\n
\n\n\nctrl b + %\n
\n\n\n\n\n
\n\n\n# 윈도우 이름 변경\n
\n\n\nctrl b + ,\n
\n\n\n\n\n
\n\n\n# 패널 전환\n
\n\n\nctrl b + {    # 왼쪽으로\n
\n\n\nctrl b + }    # 오른쪽으로\n
\n\n\n\n\n
\n\n\n# 패널 레이아웃 전환\n
\n\n\nctrl b + spacebar\n
\n\n\n
\n
\n

복사 & 붙여넣기​\n

\n
\n
\n\n\n# vi 모드 활성화\n
\n\n\n:setw -g mode-keys vi\n
\n\n\n\n\n
\n\n\n# 복사 모드 진입\n
\n\n\nctrl b + [\n
\n\n\n\n\n
\n\n\n# 복사 시작\n
\n\n\nspace\n
\n\n\n\n\n
\n\n\n# 복사 완료\n
\n\n\nenter\n
\n\n\n\n\n
\n\n\n# 붙여넣기\n
\n\n\nctrl b + ]\n
\n\n\n
\n
\n

검색​\n

\n
\n
\n\n\n# 복사 모드 진입\n
\n\n\nctrl b + [\n
\n\n\n\n\n
\n\n\n# 검색 (vi 모드)\n
\n\n\nctrl + /\n
\n\n\n\n\n
\n\n\n# 다음 검색 결과\n
\n\n\nn\n
\n\n\n\n\n
\n\n\n# 이전 검색 결과\n
\n\n\nshift + n\n
\n\n\n
\n
\n

로깅​\n

\n
\n
\n\n\n# 로깅 시작/중지\n
\n\n\nctrl b\n
\n\n\nshift + P\n
\n\n\n
\n
\n

출력 저장​\n

\n
\n
\n\n\n# 명령 모드 진입\n
\n\n\nctrl b + :\n
\n\n\n\n\n
\n\n\n# 패널 내용 캡처\n
\n\n\ncapture-pane -S -\n
\n\n\n\n\n
\n\n\n# 다시 명령 모드 진입\n
\n\n\nctrl b + :\n
\n\n\n\n\n
\n\n\n# 버퍼 저장\n
\n\n\nsave-buffer <FILE>.txt\n
\n\n\n
\n
\n

세션 관리​\n

\n
\n
\n\n\n# 새 세션 시작\n
\n\n\ntmux\n
\n\n\n\n\n
\n\n\n# 이름 있는 세션 시작\n
\n\n\ntmux new -s <SESSION_NAME>\n
\n\n\n\n\n
\n\n\n# 세션 목록\n
\n\n\ntmux ls\n
\n\n\n\n\n
\n\n\n# 세션 연결\n
\n\n\ntmux attach -t <SESSION_NAME>\n
\n\n\n\n\n
\n\n\n# 세션 분리 (세션 유지하며 나가기)\n
\n\n\nctrl b + d\n
\n\n\n\n\n
\n\n\n# 세션 종료\n
\n\n\nexit\n
\n\n\n# 또는\n
\n\n\nctrl b + :\n
\n\n\nkill-session\n
\n\n\n
\n
\n

윈도우 관리​\n

\n
\n
\n\n\n# 새 윈도우\n
\n\n\nctrl b + c\n
\n\n\n\n\n
\n\n\n# 윈도우 이동\n
\n\n\nctrl b + n    # 다음 윈도우\n
\n\n\nctrl b + p    # 이전 윈도우\n
\n\n\nctrl b + 0-9  # 특정 윈도우 번호로 이동\n
\n\n\n\n\n
\n\n\n# 윈도우 닫기\n
\n\n\nctrl b + &\n
\n\n\n
\n
\n

패널 관리​\n

\n
\n
\n\n\n# 패널 이동\n
\n\n\nctrl b + 방향키\n
\n\n\nctrl b + o    # 다음 패널\n
\n\n\nctrl b + ;    # 이전 패널\n
\n\n\n\n\n
\n\n\n# 패널 크기 조정\n
\n\n\nctrl b + :\n
\n\n\nresize-pane -D    # 아래로\n
\n\n\nresize-pane -U    # 위로\n
\n\n\nresize-pane -L    # 왼쪽으로\n
\n\n\nresize-pane -R    # 오른쪽으로\n
\n\n\n\n\n
\n\n\n# 패널 닫기\n
\n\n\nctrl b + x\n
\n\n\n
\n
\n

유용한 명령어​\n

\n
\n
\n\n\n# 설정 다시 로드\n
\n\n\nctrl b + :\n
\n\n\nsource-file ~/.tmux.conf\n
\n\n\n\n\n
\n\n\n# 시간 표시\n
\n\n\nctrl b + t\n
\n\n\n\n\n
\n\n\n# 도움말\n
\n\n\nctrl b + ?\n
\n\n\n

참고​\n

  • Tmux는 SSH 연결이 끊겨도 세션 유지
  • 여러 패널에서 동시 작업 가능
  • 세션 분리 후 나중에 다시 연결 가능
