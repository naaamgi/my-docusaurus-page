의도적으로 취약한 대학병원 웹·모바일 서비스(RKHospital) 구축 → 공격 시나리오 3개(웹/모바일/인프라) 설계·실행

AWSTerraformOpenVPNBurp SuiteKali LinuxKeePassJohn the Ripper

팀: 11명

역할: 인프라(AWS·내부망 VPN) 설계·구축 / 인프라 메인 시나리오 설계·수행 / 보고서·PPT·회의록 작성 주도

인프라 침투 시나리오 다이어그램

Phase 01 — 외부 침투 (STEP 1-2)

  • 회원가입 이메일 인증 기능에서 Thymeleaf 인라인 표현식 SSTI 발견 → WAS 리버스 셸 획득
  • PUT 토큰 발급 및 등록으로 IMDSv2 2단계 인증 우회 → IAM 임시 자격증명 탈취

Phase 02 — 클라우드 장악 (STEP 3-5)

  • S3 환자 민감 문서 다운로드
  • Bedrock 무단 호출
  • WAS 프로세스 실행 인자의 평문 크리덴셜로 RDS 환자 DB 덤프

Phase 03 — 내부망 장악 (STEP 6-9)

  • SSM 권한으로 Bastion 세션 → OpenVPN 설정 탈취
  • 공격자 전용 인증서 발급 → 사내망 VPN 진입
  • bash_history Samba 크리덴셜 → 크리덴셜 재사용 + root crontab 취약점 → root 권한 획득
  • KeePass DB 탈취 → John으로 패스워드 크래킹 → 내부망 주요 시스템 추가 장악

핵심 기여 포인트

  • AWS 3-tier 인프라 설계·구축 및 의도적 취약 환경 설정 (EC2, S3, RDS, Bedrock, IAM 등 활용)
  • AWS 인프라 + 온프레미스 내부망 침투 시나리오 직접 설계 및 테스트 수행
  • 회의록 매일 작성 및 취약점 진단 보고서, 모의해킹 보고서, 최종 발표 PPT 등 전체 문서 작성 총괄
